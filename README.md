# Shrayan Biswas - Cyber Security Portfolio

Run locally:

    pip install -r requirements.txt
    streamlit run app.py

Deploy free on Streamlit Community Cloud: push this folder to a GitHub repo, then choose `app.py` as the main file.

Edit all text in the "Content" block at the top of `app.py`. Replace `assets/Shrayan_Biswas_Resume.pdf` to update the resume download.
