## Run Locally

```bash
pip install -r requirements.txt
streamlit run app.py
```

## Deploy

Deploy free on [Streamlit Community Cloud](https://share.streamlit.io/):

1. Push this folder to a GitHub repository.
2. Connect your repository to Streamlit Community Cloud.
3. Choose `app.py` as the main file.
4. Deploy your portfolio.

## Customization

- Edit all text in the **Content** block at the top of `app.py`.
- Replace `assets/Shrayan_Biswas_Resume.pdf` to update the resume download.
